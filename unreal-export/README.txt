Unreal Engine export of Mandate of Heaven's regions.

One folder per region (zhuo = Lousang village and Zhuo County, the first chapter).
Each folder's IMPORT.txt lists the exact numbers to type into Unreal's Landscape importer.
Step-by-step instructions: docs/UNREAL_MIGRATION.md

To re-create these files after the game's maps change, double-click
Export-Unreal-Windows.bat (Windows) or Export-Unreal-Mac.command (Mac) in the main folder.
